This terraform scripts creates aws vpc and eks cluster
$ aws login 
$ terraform init 
$ terraform apply  

later to work with cluster using kubectl
$ aws eks update-kubeconfig --region <region-code> --name <cluster-name>
ex: aws eks update-kubeconfig --region "ap-south-2" --name "my-eks-cluster"

Now the cluster is ready and we can place our workload
